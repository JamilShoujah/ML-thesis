# Data

Raw and cleaned financial-aid data are intentionally excluded from this public portfolio repository.

The original project worked with private operational records. Publishing those files, row-level examples, generated model predictions, or trained artifacts could expose sensitive student or household information.

The `sample/` directory contains a tiny synthetic CSV with fake, schema-shaped rows. It is included for context only and does not reproduce the original thesis results.

A future runnable version should expand this into a complete synthetic fixture with no real individuals.
